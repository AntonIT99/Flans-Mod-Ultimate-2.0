# Built-in Category Definitions

Before researching, editing, sorting or auditing `*_categories.json`, read
`.agents/skills/flans-category-research/SKILL.md` and follow its task-specific
routing. It is the single source of category policy, property requirements,
identity/source rules, balance tables, formatting and validation.

- Edit shipped defaults here, not runtime copies.
- Historical values, generic/fictional assignments, wearable armor, and mecha
  chassis use distinct doctrines. Read the applicable reference; do not apply
  vehicle physics requirements or fictional real-item ceilings to mechas.
- Preserve existing category semantics and content compatibility. New requirements
  must agree with the actual type parser and runtime consumers.
- Update the sibling wiki for changed properties, formats, units or workflows.
  Ordinary data additions normally do not require a wiki change.
